# Store Listing: Forgot AI

## Extension Name
Forgot AI

## Short Description
Save highlights, tweets, AI responses, and articles to your personal memory vault in one click.

## Full Description
Forgot AI is your personal, frictionless memory vault. Save useful content while you browse, forget about organizing it, and retrieve it later instantly with AI semantic search.

Whether you're researching, reading long articles, or chatting with AI, Forgot AI captures the context seamlessly so you never lose an important thought again.

## Key Features
- **One-Click Highlight Save**: Simply highlight any text on any webpage and click "Save to Forgot AI" to instantly capture it along with its source URL and title.
- **Smart Content Detection**: Automatically detects and provides one-click save buttons for important content blocks (like X/Twitter posts, ChatGPT, Claude, Gemini, and Perplexity responses).
- **Zero Organization Needed**: You don't need to categorize, tag, or folder your saves. The backend AI automatically processes, tags, and organizes everything for you.
- **Semantic Retrieval**: Find any saved memory by simply asking for it. Forgot AI searches by meaning, not just exact keywords.
- **Privacy First**: Your memories are isolated to your account. The extension requests minimal permissions and never injects third-party trackers or remote executable code.

## How it works
1. **Highlight & Save**: Select text anywhere to see the minimal floating save button.
2. **Auto-Detect**: Look for the small "Save to Forgot AI" button injected seamlessly on supported platforms.
3. **Capture Intent**: Optionally add a quick note on *why* you saved it.
4. **Retrieve Later**: Open the extension or the web app to search and chat with your memory vault.

## Supported platforms/websites
- Works on any website via text highlighting.
- Native auto-detect support for:
  - X/Twitter
  - ChatGPT
  - Claude
  - Gemini
  - Perplexity
